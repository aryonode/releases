# aryo::node Firmware

Fertige Firmware-Versionen für aryo::node, den Smart-Home-Controller für LED-Streifen und LED-Panels mit Matter über Thread.

Die aryo::node-App holt sich neue Versionen von hier und spielt sie per Bluetooth auf das Board. Jede Datei ist signiert, ein Board nimmt nur Firmware an, die für seine Hardware signiert ist.

Der Quellcode ist nicht öffentlich.
